# WEPADEL v3.11.0

## Nieuw
- Beheerder kan bestaande spelers vooraf aan een speeldag toevoegen.
- Keuze voor een vaste plek op een specifieke baan of de reservelijst.
- Beheerder kan spelers op de speeldag verplaatsen of verwijderen.
- Handmatig toegevoegde spelers krijgen automatisch de status **Ik speel mee**.
- Vaste baanplekken beginnen als **Niet betaald**.
- Bij plakken van een volledig Tikkie-bericht wordt automatisch alleen de URL opgeslagen.
- Beheeronderdelen blijven scrolbaar op kleine schermen.

## Eenmalig uitvoeren
Voer `supabase-migration-v10-admin-playday-players.sql` uit in de Supabase SQL Editor.
