# WEPADEL v3.12.2

## Wijzigingen
- De compacte speeldagregels op Overzicht behouden dezelfde hoogte.
- Datum, duur, locatie, baanstatus en betaalstatus zijn verticaal gecentreerd.
- De tekst in de compacte regels is vergroot voor betere leesbaarheid.
- De mobiele weergave blijft op één regel en passend op kleine schermen.

Er is geen nieuwe Supabase-migratie nodig.
